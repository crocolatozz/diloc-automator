PMR WEB RUNNER v1.5.4 — BROWSER EXTENSION
====================================================

Cara Install / Update (Load Unpacked):
1. Ekstrak file ZIP ini ke folder lokal (misal: D:\Extensions\pmr-web-runner atau ~/Documents/pmr-web-runner).
2. Buka Google Chrome atau Microsoft Edge, ketik di address bar:
   - Chrome: chrome://extensions
   - Edge  : edge://extensions
3. Aktifkan toggle "Developer mode" (Mode pengembang) di pojok kanan atas.
4. Klik tombol "Load unpacked" (Muat yang belum dibuka kemasannya) dan pilih folder hasil ekstrak (atau klik ikon Reload jika menimpa folder lama).

Pembaruan v1.5.4 (Bug Fix & UI Polish Patch):
- Pengembalian tata letak popup.html ke mode full-bleed edge-to-edge agar menyatu rapi dengan jendela popup Chrome tanpa double-frame.
- Pembaruan highlight hasil pencarian pada options.html & options.js untuk menyorot satu kolom penuh secara vertikal (.col-search-match) dari thead hingga baris terbawah tanpa garis pembatas horizontal di tengah kolom.
- Penguatan auto-scroll horizontal otomatis saat mengetik kata kunci pencarian melalui kalkulasi offsetLeft terhadap kolom sticky kiri (.table-wrapper.scrollTo).
